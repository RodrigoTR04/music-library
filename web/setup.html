Library Open the library

Choose the folders your music lives in.

Add one folder or several. The app reads the tags and cover art from every track inside them and builds a database it can browse quickly.

Your files are only read, never changed. Formats: mp3, flac, ogg, opus, m4a, wav, aiff. Scanning takes a few seconds per thousand tracks.

Folders

    Choosing folders in the browser is turned off, because the server is open to other machines. Pass the folders on the command line instead.

    Scan

    Scanning builds the database from the folders above. Run it again whenever you add or retag music.
